# Hands On Data Lab Implementation

## Project contents
- `hands_on_data_lab.ipynb`: guided practical notebook
- `student_study_data.csv`: fictional practice dataset
- `requirements.txt`: required Python packages

## Setup
1. Install Python 3.
2. Open a terminal in this folder.
3. Run `python -m pip install -r requirements.txt`.
4. Run `jupyter notebook` and open `hands_on_data_lab.ipynb`.
5. Run the notebook cells from top to bottom.

## What you will practise
Loading a CSV file, inspecting columns and data types, checking missing values, calculating summary statistics, filtering and sorting rows, grouping data, creating charts, and writing a short conclusion.

The dataset is fictional and is intended only for learning.
